# T1D Companion Project Briefing
**Date: 2026-05-23**

## Executive Summary

The T1D Companion project is a diabetes management application with AI-powered meal analysis, glucose prediction, and personalized recommendations. The project has substantial infrastructure in place including:

- **2.5M OpenFoodFacts products** indexed in PostgreSQL
- **Working T1D Companion CLI** for meal analysis
- **Existing skill framework** for diabetes-specific queries
- **Local Ollama LLM** (Llama 3.1 8B) for natural language processing

## Working Commands

### T1D Companion Analysis
```bash
# Activate environment
source /root/t1d/venv/bin/activate

# Analyze a meal
python3 app/t1d_companion/fast_analysis.py "3 cans of coke 2 bacon rolls" post_meal_spike

# Complex meal with AI parsing
python3 app/t1d_companion/fast_analysis.py --ollama "what will happen if I eat 2 donuts and 3 cans of coke"
```

### Database Queries
```bash
# Check OFF products
PGPASSWORD=postgres psql -h localhost -U postgres -d t1d_companion -c "SELECT COUNT(*) FROM openfoodfacts_products;"

# Search foods
PGPASSWORD=postgres psql -h localhost -U postgres -d t1d_companion -c "SELECT product_name, carbs_100g FROM openfoodfacts_products WHERE product_name ILIKE '%coke%' LIMIT 5;"
```

## What's Already Built

1. **Food Normalization Pipeline**
   - Parses "3 cans of coke 2 bacon rolls and crisps" → structured items
   - Handles compound foods (bacon roll → white roll + bacon slices)
   - Falls back to regex parsing when AI unavailable

2. **Nutritional Analysis**
   - Queries OpenFoodFacts for real nutrition data
   - Calculates carbs/fat per serving using unit conversion
   - Integrates historical outcomes from food_history_90d.json

3. **Profile-Based Recommendations**
   - 12 T1D anchor profiles with different characteristics
   - Carb ratio integration for bolus estimates
   - Fat delay and exercise sensitivity factors
