🔍The Insights Engine

What It Does

Location: app/services/insights_service.py

  • Analyzes 14 days of glucose data using AI
  • Detects patterns: "you spike after pizza at 1-2 hours"
  • Generates pre-meal predictions based on history
  • Returns JSON insights with safety-compliant language

Two Methods

generate_insights()Weekly pattern analysis (spikes, trends, TIR)
predict_meal()Specific food predictions from history

Integrated Into Pipeline

Stage 6: Historical Context (demo/stage_historical_context)
    → calls app.services.historical_meal_matcher.summarize_similar_meals()
    → uses data/food_history_90d_enhanced.json (3,251 entries)
    → provides context for Stage 7: Companion Advice

🔬The Physiology Model

┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   SUGAR     │     │   STARCH    │     │   FAT       │
│   GUT       │     │   GUT       │     │   GUT       │
│ (15 min)    │     │ (3 hrs)     │     │ (3-5 hrs)   │
└─────────────┘     └─────────────┘     └─────────────┘
       ↓                   ↓                   ↓
    QUICK RISE         SLOWER RISE        DELAYED RISE
  
┌─────────────┐
│ INSULIN     │
│ COMPARTMENT │
│ (3-5 hrs)   │
└─────────────┘
       ↓
   GLUCOSE DROP

Timeline

  • Fast carbs (sugar): ~15 minutes to absorb
  • Slow carbs (bread, rice): ~3 hours to absorb
  • Fat (≥15g): Delays/stretches absorption by 2-3 hours
  • Insulin: Works over 3-5 hours, peaks at ~1 hour

📝Architecture Decision Record

DECISION 1: Canonical Runtime (30-Day Window)

✅ RESOLVED: demo/ is canonical for next 30 days

Canonical: demo/companion_pipeline_v2 (active production)
Target: app/agents (next-gen, experimental)
Bridge: Shared services in app/services/* continue working for both

Rationale: demo/ has proven production runner, validated outputs, and real user testing. app/agents/ is green-field architecture that needs integration testing before cutover.

DECISION 2: Safety Authority

✅ RESOLVED: app/ai/safety.py is final veto gate

Every stack MUST call SafetyScaffold.validate() before output
SafetyAgent deprecated for veto — becomes advisory only
No other layer may block or modify responses

Rationale: Single source of truth for policy enforcement prevents drift between stacks. All agents, stages, and services route through one validate() call.

DECISION 3: Prediction Schema

✅ RESOLVED: Single GlycemicPrediction schema

# app/schemas/prediction.py — MANDATORY for all code
required: [
  predicted_glucose_mg_dl,
  time_to_peak_minutes, 
  baseline_glucose_mg_dl,
  confidence_tier
]
optional: [
  ascii_chart,
  explanation_text,
  carb_estimate_range_g
]

Rationale: Single schema prevents field drift. demo/ and app/ converge by accepting same contract.
